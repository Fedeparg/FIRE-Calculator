---

Shuts the door on any external resource in the browser, stops exposing the database on the local network, and translates the last texts that still showed up in Spanish on the English site.

- Translates the texts that were still in Spanish inside the English version and removes code that was no longer used.
- The browser can no longer load any third-party resource, the database is no longer reachable from the local network, and the backup password is no longer visible to other programs.
